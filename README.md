# Coursework

Smaller assignments from my classes at Dunwoody College of Technology, gathered in one place. Each folder used to be its own repo.

My larger projects have their own repos. See my [GitHub profile](https://github.com/griffinhaag).

## Java

| Project | What it covers |
| --- | --- |
| [fantasy-creature-manager](java/fantasy-creature-manager) | **App Dev final.** A console app for managing dragons, unicorns, and phoenixes: an inheritance hierarchy, abilities, filtering by type, and saving/loading to a file. Includes JUnit tests for the manager and file handling. |
| [temperature-converter](java/temperature-converter) | Celsius/Fahrenheit conversion split into separate library, application, and unit-test packages. |
| [oop-exercises](java/oop-exercises) | Inheritance with shapes (area of circles, squares, rectangles, semicircles) and abstract classes with animals. |
| [abstract-classes](java/abstract-classes) | Abstract classes and constructors with user input. |

The Java projects are Eclipse projects. Use **File → Import → Existing Projects into Workspace**, or compile `src/` with `javac`.
